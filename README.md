# seafile-client — Arch Linux package

Packaging for the [Seafile desktop client](https://github.com/haiwen/seafile-client)
9.0.22, the Qt 6 applet that runs the Seafile sync daemon.

## Fork provenance

Forked from the AUR package **seafile-client**:

<https://aur.archlinux.org/packages/seafile-client>  
<https://aur.archlinux.org/seafile-client.git>

Originally packaged and maintained by **Joffrey** <j-off@live.fr>, with
contributions from **eolianoe**, **localizator** and **Edvinas Valatka**.
Many thanks to them, and to the Seafile developers at Haiwen for the upstream
project.

This fork is maintained by **Miroslav Pavleski** <miroslav@pavleski.net>.

Build with `makepkg -f`; install with `pacman -U`.
